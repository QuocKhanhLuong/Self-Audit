## Interfaces (root harness/tests will use these)

- `annotation.py`: dataclass `AnnotationState(features, logits, coordinates)`; `AnnotationExpert(channels=16,num_classes=4,k=8)`, `.start(image)->state`, `.refine(state,guidance)->state`. Small two-stride convolution encoder (GroupNorm, no stochastic/BatchNorm state), cache features. A coarse head seeds initial probabilities; dynamic attention then shared residual writer produces A0. Refine uses same writer, A0 probabilities and `guidance.detach()` ONLY in coordinate generator's condition; guidance has no path directly to values or writer. Logits full image resolution, features /4. Add optional `coordinate_override` to refine for causal tests. Do not detach actor feature/logit paths. Return actual coordinates.
- `reference_free_auditor.py`: frozen dataclass `AuditObservation(image, logits)` with classmethod `.from_state(image,state)` validating AnnotationState, floating 4-class logits, detached cloned tensors; no arbitrary kwargs, GT or metadata. `FrozenImageAnchor` has registered fixed intensity/local-average/Sobel filters, no trainable params, normalizes per image; output 4 channels at input resolution. `ReferenceFreeAuditor(num_classes=4,hidden=16)` owns anchor and small Conv-GELU-Conv-softplus risk head; `forward(observation)->risk [B,1,H,W]`, detaches observations. `intrinsic_risk(observation)->[B,1,H,W]` under no_grad: per-class hard-prediction region mean of anchor features; per-pixel mean squared residual divided by per-channel image variance+1e-4; add 0.05 times horizontal+vertical prediction-boundary penalties weighted by exp(-mean feature difference squared), averaging two incident directions. Empty classes safe. `quality(observation)->[B]` = negative mean intrinsic risk, not Dice, class-permutation invariant. `rf_loss(auditor,observation)` MSE(risk, intrinsic_risk.detach()). No GT-derived corruption ranking. Auditor learns this explicit proxy; it cannot identify semantic class truth. No learned anchor or masked GT reconstruction.
- `audit_trigger.py`: `AuditTrigger(feature_channels=16)`; `.state_features(state)->[B,D]` detached pooled actor features, four mean probabilities, mean normalized entropy, coordinate mean displacement/spread (document D); `forward(features)->[B]` scalar predicted *net intrinsic audit value*. `select(values,budget_fraction=0.5)->bool[B]` no_grad positive top floor(B*budget_fraction), stable ties by index. Explicit batch budget coupling, NOT a per-sample invariance guarantee. `trigger_loss(trigger,features,values)` MSE to detached values.
- `replay.py`: `AuditReplay(capacity=256,seed=0)` stores ONLY detached cloned RF observations/features/value/step. `.add(observation,trigger_features,values,step)` split by row; `.sample(n,current_step,max_age=8)` uniform seeded sample of fresh records -> dict with observation,features,values,steps or None. Never labels/corruption metadata. No prioritization or false off-policy unbiasedness claim. Stale values expire.

Policies none/always/random/entropy/periodic/learned. none exact A0, zero auditor calls. Only invoke q on selected rows; subselect state, refine those rows, scatter logits. Random/entropy choose floor(B*fraction); periodic chooses all every period. Learned threshold+cap above. Inference no exploration. Actor gradients from final logits reach no auditor/trigger parameters. Count read_calls as sample-level dynamic reads B+n_selected; audit_calls=n_selected.
