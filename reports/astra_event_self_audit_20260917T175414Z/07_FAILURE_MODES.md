No smoothing, extra candidate search, Candidate C, additional anatomy module, post-hoc threshold change or alternate A0 is added to rescue a failed gate. A fixed coordinate override tests the guidance path exactly; K/V hooks test source dependence without changing query features or the writer's local input.

## Predeclared progression

Stage A: API/gradient/firewall, identity skip, paired-state tests, finite losses and evidence sensitivity. A fixture that produces both trigger actions is only software evidence. Real positive/negative intervention targets must be counted independently.

Stage B: bounded real ACDC, fixed manifest, complete validation patients, natural RF/true utility relation. Short training cannot establish final clinical accuracy. Stage C runs bounded simple controls to diagnose whether an apparent effect is merely another read or selection budget. Stage D (longer training) is conditional on these gates; a negative signal result blocks escalation. M&Ms remains untouched.

A patient-level bootstrap is appropriate for final uncertainty estimates; with very few seeds/patients, report descriptive uncertainty and avoid equivalence claims. State-level oracle utility is an analysis upper bound, not a deployable baseline and not a training signal.
