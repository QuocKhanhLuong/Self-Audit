# Astra's final decision

**C — REFERENCE-FREE AUDIT SIGNAL IS TOO WEAK.** Keep a supervised Auditor as the controlled research reference and investigate event-triggered intervention separately. This verdict applies to the **implemented fixed-feature region/edge energy and its distilled guidance**. It does not prove that every reference-free signal is impossible.

## What the new baseline actually is

A supervised compact segmenter performs a learned dynamic QKV read before A0. A detached scalar value head may invoke a learned spatial Auditor, trained only to imitate fixed image–prediction compatibility. Guidance changes the next support coordinates; the shared reader/writer produces one refinement. Skip is exact identity. Sparse audit/skip twins train net intrinsic value, and replay drives slower RF/Trigger updates. There is no GT quality target, FIX/REGRESS label, runtime GT, candidate bank, historical Candidate C, or claim of mask-free Annotation training.

Its scientific question is defensible; the present proxy is not sufficiently validated to become the new core method.

## Evidence driving C

1. The RF score has an exact semantic-permutation blind spot. In an evaluation-only extent test it preferred incorrect myocardium dilation on 67.3% of nonempty slices, while correctly penalizing erosion. A smooth, image-compatible mask is not guaranteed correct.
2. On natural frozen transitions, patient-level RF/true improvement Spearman changed from +0.250 and +0.433 to -0.332 across seeds. Slice-state ranking was weak. This is not a stable utility reference.
3. The reader demonstrably uses sampled source evidence, yet removing audit guidance has negligible or favorable mean effects. The desired audit-to-useful-reading link is unproven.
4. Learned invocation nearly collapsed at validation. Fitting fresh frozen targets repaired action diversity, but the learned policy's true improvement per call remained close to matched random in that one-seed diagnostic. Fixing target tracking alone would not establish the method.
5. Unguided extra reading reached 0.2669 mean retained Dice versus 0.2607 always-audit and 0.1822 learned. All actors were strongly underfit, and no prespecified convergence threshold was reached. There is no evidence of faster accurate learning.

This is why B (“one technical fix”) would be too optimistic. D would overstate evidence that *all* learned triggers are unnecessary, and E would overstate evidence against dynamic supports—the source intervention tests show that reading itself matters. A is not supported by this evidence.

## What remains potentially novel

A reliable **action-specific reference-free contrast** that predicts the incremental value of an audit-guided read, coupled with a demonstrated causal benefit from redirected source evidence and improved convergence at matched compute. Existing active perception, value of computation, QC, quality-guided learning and dynamic attention already cover the broad ingredients (02). The present combination is diagnostic engineering, not a demonstrated novelty claim. No journal acceptance prediction is justified.

## One next experiment, not another module

**PROPOSED: a frozen-state supervised-utility control with the same read intervention.** On training patients only, fit a small action-value control to true audit-versus-skip improvement for a fixed, meaningful A0 and the same K/writer/support controller. Keep validation patients for evaluation, freeze the compared actor state and compare learned, entropy, random and offline oracle at the same realized call count. This deliberately relaxes the RF audit-training constraint for a control; it is not relabeled as the proposed method.

Its purpose is to identify whether *when to intervene* has headroom once target validity is removed as a bottleneck. If even that control cannot beat entropy/random or the oracle headroom is tiny, stop trigger complexity. If it can, RF work needs an independently validated semantic/image anchor before training an event policy on its scores. Do not add temporal, hierarchy, EMA, bilevel optimization or more proposal modules to evade the failed simple baselines.

This control is not automatically authorized as a new long GPU run by the present report. No such run or production patch was launched. The new isolated diagnostic implementation is preserved for reproducibility; existing REW, Candidate C, canonical and mask-free code remain distinct.
