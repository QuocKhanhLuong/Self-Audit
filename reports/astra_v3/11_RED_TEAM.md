# Root adversarial review and disagreement resolution

**Current rejection recommendation: NO-GO; TEACHER_NOT_READY.** The blocking issue is trustworthy named pseudo labels. Good tensor plumbing does not resolve it. Root conclusions below supersede worker assertions; raw worker reports are retained as investigation records, not accepted ground truth.

## Attacks that survive review

1. **Semantic circularity.** The region classifier has no named targets or typed evidence generator. Confidence, reconstruction, symmetric clustering and agreement can reinforce arbitrary class assignments. External semantic evidence must have an auditable source.
2. **Hidden supervision.** Historical image acquisition used paired mask presence; conventional ACDC/M&Ms training loaders consume masks. Checkpoint ancestry, crop rules, phase fields and threshold/checkpoint selection all need separate disclosure. Image-only weights are not automatically pristine because a file is named pretrained.
3. **Confirmation bias and coverage collapse.** The frozen combined seed arm has high aggregate foreground precision but fails MYO precision and RV coverage. Four patients lose all foreground in the second phase. More conservative filtering can remove the information needed for learning.
4. **No independent .91 evidence.** The bounded heuristic experiment is not a trained-v3 result. Historical dev masks have already informed project development. No sequestered final evaluation exists in this audit.
5. **Refinement and adaptive novelty.** Fixed-K spatial adaptation is not variable compute within a profile. Manual profile choices are not an uncertainty/hardware policy. An extra refiner must beat ordinary extra computation at matched budgets.
6. **Resource claim mismatch.** Random-weight CPU/MPS timing cannot be paired with unmeasured trained-model accuracy. A12-core24GB host using 4 torch threads is not the4-core8GB target. Teacher preparation and runtime/UI/export must be accounted separately.
7. **Cross-dataset gap.** No M&Ms execution, native-geometry proof, or zero-shot transfer has occurred. Joint training would not fill the zero-shot gap.
8. **Application scope.** Native-grid array restoration is not verified physical-coordinate restoration; a display overlay can look plausible despite an affine error. UI cannot rescue a failed teacher.
