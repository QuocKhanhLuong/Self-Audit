## Temporal state machine and exact replay

Each active sample holds at most one most-recent accepted ORDINARY transition record; first turn runs ordinary annotator. Only accepted ordinary actions become eligible. A rejected action HALTs and never becomes history. C consumes predicted local FIX=0 / UNCHANGED=1 / REGRESS=2 evidence for precisely that accepted record. C or direct-rollback acceptance invalidates the ordinary replay record and leaves an ineligible `previous_kind` diagnostic. The following active turn uses ordinary annotation with actual accepted-transition audit evidence. This deliberately avoids recursive replay of restitution-on-restitution; never retain an older ordinary record as the latest accepted action.

C1: replay factual support with same fixed inputs/modes/numerics; compare factual output with strict atol/rtol and log max absolute/relative errors. Also assert stored factual output matches current retained output before transfer. A mismatch uses NORMAL annotation for that turn, logged replay_failure/stale_record. Baseline path must remain unaffected. If initial collection uses autocast, replay the same autocast context or disable C for numerical mismatch; do not loosen tolerance until replay appears to pass.

C2: on predicted REGRESS pixels (thresholded mass; report raw/selected mass), minimize weighted CE of replay output against pretransition winning class plus lambda mean squared displacement in FEATURE-PIXEL units. Optimize only realized coordinates Q, jointly across all internal supports, bounded by image domain and one-feature-pixel axis-wise trust region. Degenerate size-one axes have zero physical movement. Starting factual point is feasible. Use one gradient at factual P; normalize/projection rule must be explicit. At most two candidate checks total, e.g. full proposal and half step. A factual identity forward can also provide the differentiable base objective if safe; report actual forward/backward counts, no hidden second base forward. No R, zero/nonfinite gradient, nonfinite replay, infeasible candidates or no strict finite objective improvement returns P. One backward only; no double backward or optimizer on model parameters.

FIX protection uses ALL pixels at the E_FIX threshold and the deterministic factual argmax, including exact ties and small positive margins; require candidate argmax preservation plus each candidate output margin at least margin_fraction times factual margin. Log tied/near-tied counts separately without excluding them from protection. Explicitly check the FINAL C3 candidate winning classes too: floating arithmetic and approximate C1 must not invalidate the mathematical convex-mixture argument. C without FIX removes this constraint only; it retains C1, bounds, budget and Auditor gate.

C3: `candidate = current + sigmoid(recorded_gate) * (counterfactual_logits - factual_logits)`. Gate is spatial and class-shared. The entire restitution innovation/gate is detached in training; gradients flow through current retained state only. No invented extra training of a detached gate. When Q=P, subtract the exact stored factual output from itself so identity fallback is exactly zero, not a numerical replay residue. Official Auditor always judges final candidate, inputs detached, acceptance strict delta_q>tau, reject->HALT. No GT in proposal or replay. Oracle mode remains explicitly analysis-only and cannot silently supply solver evidence.

Use `torch.inference_mode(False)` plus `enable_grad()` only inside solver and clone all needed inputs into ordinary detached tensors there. Prefer functional replay with detached parameters/buffers, preserving module flags and accumulated `.grad`; if temporary parameter requires_grad flags are used, restore in finally and prove no leakage with pre-existing grads and failures. Input image, encoder, auditor and annotation parameters receive no SOLVER gradient. Existing ordinary joint path retains its intended gradients. Inference-mode and AMP behavior require actual tests, not only inspection.
