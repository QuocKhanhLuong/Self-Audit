## Main conclusion and central nominations

The stride-4 split is an exact coordinate construction in real arithmetic, not a demonstrated observation model of anatomical truth. It is a useful controllable baseline but does not deserve privileged status in the research conclusion. A replacement should first justify what the teacher observes, what image information rules out, and which uncertainty remains; a larger detail decoder cannot answer those questions.

Nominate **R2-C5** for mechanism review: a conditional stable-recovery result for combined teacher and image constraints, including noise, operator error, approximation error, and optimization residual. Its useful contribution here is exposing the missing assumptions, not inventing a new inverse-problem theorem. Nominate **R2-C7** for setting/prior-art review: compare exact preservation, soft observation fit, and an explicitly bounded trust region; there is no unconditional ordering. Nominate **R2-C3** as a narrower implementation-facing result: zero detail, Jensen, and shared gradients are different statements with different assumptions.

## Information and notation contract

Let `n` be the number of valid native pixels, `C = 4`, `p* ∈ (Δ_C)^n` a latent named class distribution, and `ell ∈ R^(n×C)` logits. Neither `p*` nor a correct image-to-anatomy likelihood is observed here. A hard segmentation is an additional argmax/margin claim, not synonymous with logit recovery.

`D` averages disjoint student 4×4 cells on the padded grid; `U` replicates; `P = I - UD`. `H_T` is reserved for a declared teacher observation operator on a latent target, if one can be justified. The historical computation `Q = T(X, M, F, A, ...)` is not automatically `H_T p* + noise`. `R` denotes deterministic spatial transport of a stored array, not a new teacher evaluation. `K_X p ≈ b_X` denotes an explicitly chosen image-derived relation; its anatomical residual is a latent misspecification term. These symbols must not be conflated.

All norms are Euclidean/Frobenius unless stated. Zero support removes an observation; UNKNOWN=255 is abstention. All maps are restricted to valid support before anatomical claims. Repeated teacher/image-derived sources can be dependent; none of the deterministic bounds below assumes independence or offers a sample-size gain from duplicate rows.

## Evidence cards

### R2-C1 — Transport cannot create observations; the true nullspace need not be ker D

**Status:** CODE_FACT + DERIVED_RESULT. **Scope:** deterministic resampling and a separately declared linear teacher observation model. **Assumptions:** fixed geometry and support; `y = H_T p`; `R` acts only on already stored values.

**Formal claim.** For every linear `R,H_T`, `rank(R H_T) ≤ rank(H_T)` and `ker H_T ⊆ ker(R H_T)`. Thus increasing the array size, including 48×48 to native size, does not add independent constraints on `p`. For fixed positive support `w`, transported probabilities have the form `q' = diag(Rw)^(-1) R diag(w) q` on supported rows, so their rank in `q` is no greater than the source dimension. Renormalization or nonlinear interpolation cannot turn a deterministic function of one cache into independent evidence. Geometry/support may themselves contain information, but that information comes from their source and must be counted once.

**Proof.** Composition cannot increase rank; `H_T v = 0` implies `R H_T v = 0`. The displayed mass/support expression follows from fixed-denominator normalization. The source code's final simplex renormalization is redundant in exact arithmetic for simplex Q, but protects floating point. No assumption that support is independent of anatomy is made.

**Counterexample to equating operators.** With four native values, let `D` average `(1,2)` and `(3,4)`, while `H_T` averages `(2,3)` only. `v = (1,-1,0,0)` lies in `ker D` but `H_T v = -1/2`. A D-preserving detail update can alter the actual teacher observation. Conversely, if teacher cells are unions of student cells, `H_T = B D` gives `ker D ⊆ ker H_T`, so the hard student split is more restrictive than actual teacher consistency. Misaligned/non-nested grids generally lack either inclusion.

**Closest prior result:** linear algebra underlying null-space networks [S1]; FeatUp's re-evaluated jittered views [S4] are a genuinely different information mechanism. **Evidence:** data.py:509–523; probe `resized_rank` has 4 source rows and 16 transported rows but rank 4 in both. **Implication:** record teacher receptive/observation grid, native geometry, support and any teacher reruns separately from student stride. **Limitation:** historical Q may not admit a known linear anatomical observation model at all. **Falsifiable prediction:** pure resizing preserves every source-null perturbation; rerunning a frozen backbone on shifted native crops can reduce an empirical feature nullspace, but only if the new outputs are not reconstructible from the original cache. That would be new feature evidence, still not named labels.

### R2-C2 — Split capacity is full only before bounds; logit preservation is not probability preservation

**Status:** DERIVED_RESULT + COUNTEREXAMPLE. **Scope:** output space, not neural representability. **Assumptions:** complete equal-size cells, `DU = I`, initially unbounded and free `a,r`.

**Formal claim.** Every `ell` can be written `ell = U a + P r`: take `a = D ell`, `r = ell`. `P` is an orthogonal projector for uniform cell averages, and the decomposition into coarse component and projected detail is unique; the raw `r` is not unique. Therefore an unbounded split alone does not lose output-space capacity. A fixed `a`, a bounded branch, finite network width, and its optimization each impose additional restrictions.

For the actual per-class branch `s_i = b tanh(r_i)` and `delta = P s` in a cell of `k = 16` pixels, `sum_i delta_i = 0`, `max_i delta_i - min_i delta_i < 2b`, and `|delta_i| < 2b(1 - 1/k)`. Conversely any zero-mean scalar-class delta with range `< 2b` has such a finite raw representation: choose a constant shift placing all `delta_i + c` in `(-b,b)` and invert tanh. The closure admits equality. This is a precise per-class capacity limit, not a universal probability-space characterization because classwise logit gauges can change a representation.

**Proof.** Projection subtracts one cell mean, preserving within-cell ranges. Extremizing one coordinate against the other `k-1` bounded coordinates gives `2b(k-1)/k`. Across two classes the per-pixel margin perturbation is bounded by `4b(k-1)/k`; hence a fixed coarse winning margin greater than this cannot be flipped anywhere in that cell. At `b = 1,k = 16`, the sufficient no-flip margin is 3.75. This is a sufficient obstruction, not a necessary condition for a boundary to be impossible.

**Probability counterexample.** Binary logits `(2,0)` with first-class detail `(+2,-2)` over two pixels preserve mean logits exactly. `softmax(mean ell)_1 = 0.880797`, whereas `mean softmax(ell)_1 = 0.741007`. Hard `D ell = a` neither preserves class mass nor teacher probabilities. Using `D softmax(ell)` defines a different, nonlinear observation model; it should be judged separately.

**Closest prior result:** range/null decomposition [S1]; spectral continuation allows correction beyond exact null directions [S2]. **Evidence:** model.py:106–108; probe `split`, `capacity_limit`, `probability_mismatch`. **Implication:** compare bounded split, unbounded split, and a conventional dense head with identical information/objectives; separate capacity from supervision. **Limitation:** no dense neural universal approximation or improved anatomy is proved. **Falsifiable prediction:** manufactured boundaries requiring an opposing-class margin beyond the bound fail with fixed coarse logits but can succeed after coarse relaxation or a changed bound; test probabilities and argmax separately.

### R2-C3 — The zero-detail invariant, Jensen, and parameter coupling have different scopes

**Status:** CODE_FACT + DERIVED_RESULT + COUNTEREXAMPLE. **Scope:** current computational graph and explicitly defined alternative losses. **Assumptions:** finite arithmetic, zero final detail head, no native loss or auxiliary parameter mutation, optimizer initial moments zero; no imported nonzero optimizer state.

**Formal claim A, current zero detail.** `L_coarse(a)` has `∂L/∂r = 0` in output coordinates. The currently enabled feature/coarse objectives do not use the detail-only parameters. The zero final detail weights/bias remain zero under ordinary AdamW initialized with zero state, even while their shared input features change. Therefore `P[b tanh(raw_detail)] = 0` for the active path. This does not imply all shared layers are frozen, nor that a nonzero detail head would remain functionally unchanged.

**Proof A.** There is no computational path from these objectives to the final detail head. Zero weight decay preserves zero; unused parameters have no loss gradient. Any input multiplied by a zero head yields zero. Once a head is nonzero, changing its shared inputs changes detail despite zero gradient to detail-only parameters.

**Formal claim B, Jensen.** Fix one coarse logit vector `a`, use a constant target `q ∈ Δ_C` throughout one complete cell, uniform positive pixel weights, and zero-mean logit detail. Then `k^(-1) sum_i CE(a + delta_i,q) ≥ CE(a,q)`. Equality holds exactly when all `delta_i` differ only by multiples of the all-ones class vector; under zero mean this is `delta_i = c_i 1`, with `sum_i c_i = 0`. Thus zero detail minimizes the loss, but it is not a unique raw-logit minimizer. Finite log-sum-exp is strictly convex only on the class-centered subspace. Positive target probabilities are not needed for this equality statement.

**Proof B.** The target-linear terms average to `-q·a`; apply Jensen to log-sum-exp. Its Hessian is `diag(p)-pp^T`, whose only null vector for finite logits is the all-ones vector. A spatially varying class-independent gauge is invisible to softmax.

**Limits/counterexamples.** Unequal weights require a correspondingly weighted zero-mean constraint; current `D delta = 0` is unweighted. With weights `(0.9,0.1)`, constant binary target `(0.8,0.2)`, and details `(theta,0),(-theta,0)` at `a=0`, the loss derivative is `-0.24`, so zero is not stationary. Partial validity, padding, bilinearly varied targets, spatially varying support, and a loss on pooled probabilities all escape the stated Jensen result. Artificial interpolated variation can generate gradients without adding observations.

**Network gradient statement.** For native `g = ∇_ell L`, `∇_theta L = J_a^T U^T g + J_r^T diag(b sech²(r)) P^T g` (with `J_r` defined for raw detail). A nonzero output detail gradient does not guarantee a nonzero weight gradient: its contraction with hidden features may vanish. Even freezing coarse-head weights does not freeze `a` if its encoder/decoder changes. Independent branches or stopping shared paths can simplify controls, but protecting actual coarse outputs requires checking actual parameter displacement or freezing all paths producing them.

**Closest prior result:** convexity of log-sum-exp and chain rule; these are classical, not novelty. [S1] is the output-space null network comparator. **Evidence:** model.py:76–108; runner.py:437–474; probe `jensen` and `shared_gradient` (detail 0.5→0.6 through shared state; detail parameter gradient remains absent). **Implication:** native-positive tests need nonzero head gradient and actual weight/output change; the constant replicated-target control needs equal complete-cell weighting to invoke Jensen. **Limitation:** no nonlinear optimizer convergence theorem is claimed. **Falsifiable prediction:** a deliberately varying native signal with hidden features aligned to its gradient updates the zero head on the first step; detail-stem gradients can initially be zero behind that head and appear on later steps.

### R2-C4 — Padding and precision change what exactness means

**Status:** CODE_FACT + DERIVED_RESULT + EMPIRICAL_OBSERVATION (manufactured only). **Scope:** boundary cells and arithmetic. **Assumptions:** the implemented `P` averages all padded positions; validity is applied separately.

**Formal claim.** On a partially valid cell, `sum_all delta = 0` does not imply `sum_valid delta = 0`. A valid-pixel loss through `P` can backpropagate into padded detail coordinates through the mean subtraction. A validity mask on the loss alone does not remove that coupling. If an alternative uses a valid-only mean `D_v`, its matching lift and metric must be declared: `U D_v` is not generally an orthogonal projector in the unweighted full-grid Euclidean metric. Empty cells must be excluded.

**Proof/counterexample.** Center `(1,-1,-1,-1)` to `(1.5,-0.5,-0.5,-0.5)`. The padded mean is zero, while the first valid pixel has mean 1.5. Differentiating the mean subtraction directly gives the padded-coordinate coupling. This does not establish that current coarse-only execution learns a padding artefact; its detail remains zero.

**Precision.** `D P = 0` is a real-arithmetic identity. The manufactured amplitude-11 probe gave maximum residuals `6.66e-16` (float64), `7.15e-7` (float32), `0.00122` (float16), `0.015625` (bfloat16). These values are examples, not a hardware-independent tolerance law. Cancellation, scaling, operation ordering, and dtype matter. A production claim should compare error against dtype/scale and aggregate accumulation policy, not demand bitwise zero universally.

**Closest prior result:** weighted projections and floating-point cancellation; elementary. **Evidence:** layers.py:8–26; model.py:89–114; probe `padding` and `finite_precision_DP_residual`. **Implication:** test complete-cell, boundary-cell, empty-support, large/small logit scales and deployment dtype separately. **Limitation:** no target-GPU arithmetic was tested. **Falsifiable prediction:** changing padded raw detail while holding valid raw detail fixed changes valid projected detail in a partial cell; it should not be described as new anatomical evidence.

### R2-C5 — Positive recovery requires complementary image information with a quantitative gain

**Status:** DERIVED_RESULT, classical conditional recovery lemma specialized to this setting. **Scope:** finite-dimensional probability fields or another explicitly selected representation. **Assumptions:** a declared admissible set `S`; known linear map `A = [W_T H_T; sqrt(lambda) K_X]`; measurement vector `y = [W_T q; sqrt(lambda) b_X]`; finite `lambda ≥ 0`; a target `p*`; and an honest residual bound. `W_T` may remove unsupported rows but is not assumed to be calibrated precision. Both `H_T p*≈q` and `K_X p*≈b_X` are latent anatomical assumptions in this project.

**Formal claim, well-specified.** Define

`alpha_S = inf { ||A(u-v)|| / ||u-v|| : u,v ∈ S, u ≠ v }`.

Suppose `alpha_S > 0`, `p* ∈ S`, `||A p* - y|| ≤ epsilon`, and the fitted `p_hat ∈ S` satisfies `||A p_hat - y|| ≤ epsilon + rho`, where `rho ≥ 0` is an optimization slack. Then

`||p_hat - p*|| ≤ (2 epsilon + rho) / alpha_S`.

**Proof.** The triangle inequality bounds `||A(p_hat-p*)||` by `2 epsilon + rho`; apply the definition of `alpha_S`. For a linear subspace this is its smallest restricted singular value. For a nonlinear set, global secants rather than a single tangent are required. A merely trivial joint nullspace is insufficient for a uniform positive gain on arbitrary nonclosed/noncompact sets.

**Misspecification extension.** Suppose instead `p_0 ∈ S`, `||p_0-p*|| ≤ eta`, `||A|| ≤ L`, and `||A p* - y|| ≤ epsilon`. If the solver reaches residual at most the residual of `p_0` plus `rho`, then

`||p_hat-p*|| ≤ eta + [2(epsilon + L eta) + rho] / alpha_S`.

Indeed `||A p_0-y|| ≤ epsilon+L eta`; compare `p_hat` and `p_0`, then add eta. If actual observations use `A_true = A + Delta_A`, `||Delta_A|| ≤ tau`, and `||p*|| ≤ B`, replace epsilon with `epsilon_noise + tau B` plus the declared image-relation residual. Correlated errors are allowed because the bound is deterministic. A lower observed training loss alone does not reveal epsilon or eta.

**Constructive image-region specialization.** Let `K_X` be the incidence matrix of an image-derived graph and posit that `p*` is constant on each connected component. Let `V` have normalized component-indicator columns. Then `ker K_X = range(V)` and teacher observations distinguish all component values iff `H_T V` has full column rank, class constraints/gauge handled appropriately. In the hard graph model, a least-squares estimate has `||p_hat-p*|| ≤ ||noise|| / sigma_min(H_T V)`. This provides a concrete positive mechanism: reliable image relations reduce unknown degrees of freedom, and nondegenerate teacher mixtures identify the remaining region values. Approximate region constancy pays eta; false image edges/bridges can make eta large.

**Counterexample/negative control.** Four pixels, image components `{1,2}` and `{3,4}`, teacher only observes their overall mean. Both `(0.9,0.9,0.1,0.1)` and its class swap satisfy the same image constraints and teacher observation. Clear boundaries do not name regions. One observation per component removes this algebraic ambiguity, subject to correct semantics. Duplicate mixed observations do not.

**Closest prior result:** [S3] Proposition 2.2 gives the standard `2 delta / gain` tangent-cone bound; [S1] obtains convergence on a learned admissible manifold. [S7] supplies recent graph-null-space approximation theory but its predictor is trained against true target images. **Evidence:** probe `joint_observation`: rank 3 before identifying regions, rank 4 after; good `sigma_min = 0.707107`, error `0.0318198`, noise/sigma bound `0.0324037`. Probe `uniqueness_without_stability` keeps rank 2 while a fixed 0.001 perturbation causes solution displacement from 0.001 to 1.0 as near-dependence increases.

**Implication:** choose a measurable image relation and an admissible class before designing a high-capacity detail learner. Inspect whether image constraints add complementary directions, not simply whether an image-energy optimum is unique. **Limitations:** `S`, truth membership, epsilon, eta, correspondence to named anatomy and the relevant worst-case alpha are not operationally certified without additional assumptions/evidence. A numerically computed gain for a chosen graph can certify that graph's conditioning, not its anatomical correctness. **Falsifiable prediction:** synthetic perturbations in a common nullspace stay unresolved; adding complementary observations improves stability according to restricted gain; adding a false anatomical relation can increase alpha while increasing truth error.

### R2-C6 — Softmax gauge and nonlinear sensitivity must be separated from anatomy

**Status:** DERIVED_RESULT + COUNTEREXAMPLE. **Scope:** locally smooth observation maps on class-centered logits. **Assumptions:** fix gauge `sum_c ell_ic = 0`; restrict to a declared neighborhood/admissible directions; every probability on the connecting segment is at least `m > 0` for the lower softmax bound.

**Formal claim.** For softmax Jacobian `S_p = diag(p)-pp^T`, `S_p 1 = 0`. For any class-centered `v`, `v^T S_p v ≥ m ||v||²`, while `||S_p||_2 ≤ 1/2`. Integrating along a gauge-centered logit segment yields `m ||ell-ell'|| ≤ ||softmax(ell)-softmax(ell')|| ≤ (1/2)||ell-ell'||` when the same m bounds the whole segment. The lower bound follows from strong monotonicity and Cauchy-Schwarz. The upper bound is a standard covariance/Gershgorin bound.

For a nonlinear joint observation map `F`, suppose `J = DF(ell*)` has restricted gain at least `sigma > 0` on the relevant secants and `DF` is L-Lipschitz on connecting segments of radius R. Taylor's remainder gives `||F(ell)-F(ell*)|| ≥ (sigma - L R/2)||ell-ell*||`. If `sigma - L R/2 > 0`, noisy residual comparison yields a local recovery bound with that denominator. A full neighborhood pairwise bound needs a corresponding uniform/reference-J argument; a Jacobian at one point is not a global injectivity theorem.

**Proof details.** `v^T S_p v = min_c sum_j p_j(v_j-c)^2 ≥ m min_c sum_j(v_j-c)^2 = m||v||²`. Taylor's integral remainder has norm at most `L||ell-ell*||²/2`. Softmax gauge directions would otherwise force a zero singular value even when probabilities are perfectly identified.

**Counterexamples.** Saturated probabilities drive m toward zero; logits can vary greatly while probabilities barely change. A class permutation can remain consistent with an image relation and an uninformative teacher even after fixing the additive softmax gauge. These are different ambiguities. `F(t) = (cos t,sin t)` has nonzero derivative everywhere but is not globally injective on R. Thus local sensitivity, global uniqueness, and named anatomy are three different claims.

**Closest prior result:** classical Jacobian/Taylor inverse stability, with [S3] as linear comparator. **Evidence:** explicit proof; probability counterexample in C2. **Implication:** measure observation response in probability/class-centered logit coordinates; use a declared local perturbation set, and report saturation. **Limitation:** the segment m, truth-centered region and its anatomical validity are latent; a local numerical singular value is not a label-free accuracy certificate. **Falsifiable prediction:** making logits confidently wrong can reduce observed sensitivity without improving semantics; class permutation tests remain a necessary negative control.

### R2-C7 — Hard, soft, and trust-region observation fits have different bias/noise tradeoffs

**Status:** DERIVED_RESULT + COUNTEREXAMPLE + PROPOSED_NOT_APPROVED comparison. **Scope:** output-space observation constraints, distinct from maintaining the algebraic D/U parameterization. **Assumptions:** some declared `H` relates a chosen output representation to teacher evidence, with possible error `e = y-Hp*`.

**Formal claims.** Any exact fit `H p_hat = y` has `||p_hat-p*|| ≥ ||e||/||H||` when H is nonzero. No nullspace-only correction removes this observation-space bias. A residual ball `||H p-y|| ≤ epsilon` contains truth if `epsilon ≥ ||e||`; it need not contain truth if epsilon is chosen too small. A soft penalty can correct observation error when independent image information is sufficiently accurate, but can also move away from correct teacher evidence under a wrong image prior.

**Constructive noisy example.** Let `y_T = z* + e_T`, `y_X = z* + e_X`, and minimize `w_T(z-y_T)^2 + w_X(z-y_X)^2`. The solution is `(w_T y_T+w_X y_X)/(w_T+w_X)`. With independent zero-mean errors of known variances and inverse-variance weights, variance is `(sigma_T^-2+sigma_X^-2)^-1`, smaller than either alone. With dependence, include `2 w_T w_X Cov(e_T,e_X)/(w_T+w_X)^2`; duplicating the same signal cannot provide the independent gain. Bias terms also persist. These statistical assumptions are not established for Q and image energies derived from the same cine.

**Proof/counterexample.** The hard lower bound is `||e|| = ||H(p_hat-p*)|| ≤ ||H||||p_hat-p*||`. Scalar truth 0.8, teacher 0.6, correct image 0.8: hard error 0.2, equal-weight soft error 0.1, truth-covering radius 0.2 allows zero error. Swap the situation to correct teacher 0.8 and incorrect image 0.6: the soft result is worse. A trust radius can limit damage but cannot determine which source is right.

**Closest prior result:** [S2] extends exact null-space corrections into unreliable nonzero singular directions; [S1] includes regularized initial inverses rather than treating all observations as noiseless. The comparison is classical regularization, not novelty. **Evidence:** `hard_soft_trust_scalar` is an oracle manufactured illustration; no radius was estimated on patients. **Implication:** retain D/U as one coordinate ablation if desired, but compare objectives on the actual teacher observation representation. Do not call free trainable coarse `a` a fixed-teacher hard constraint: current D/U itself does not force a to remain equal to Q. **Limitations:** selecting a radius or source precision from no-GT residuals alone does not calibrate anatomical error; feature agreement and confidence do not supply the missing guarantee. **Falsifiable prediction:** a factorial manufactured study varying teacher bias, image-relation error, support, misregistration and dependence will reverse method rankings; a method claiming unconditional dominance should fail.

### R2-C8 — A narrower, testable native-detail comparison is preferable to architectural escalation

**Status:** PROPOSED_NOT_APPROVED. **Statement:** evaluate the evidence mechanism and proposal quality before asking a large student to amortize it. **Scope:** future design only; no approval to implement or run on patients.

**Assumptions/formal hypothesis.** Suppose an image-derived proposal `p_tilde(X,Q)` reduces a declared synthetic truth error by a margin larger than its transfer error, and a student `p_theta(X)` approximates it with `||p_theta-p_tilde|| ≤ epsilon_transfer`. Then `||p_theta-p*|| ≤ ||p_tilde-p*||+epsilon_transfer`. To establish improvement over teacher baseline `p_base`, one additionally needs the *strict* comparison `||p_tilde-p*||+epsilon_transfer < ||p_base-p*||`; neither inequality is known on anatomy here. This is the missing bridge, not a proposed certificate.

**Proof:** triangle inequality. **Counterexample:** a student can perfectly copy a sharp incorrect proposal, improve image energy and teacher consistency, and worsen class assignment. **Closest existing mechanisms:** image-guided interpolation [S4,S5,S6], null-space/regularized reconstruction [S1,S2,S7], and coarse-plus-fine point prediction [S8]. **Evidence references:** C1–C7 identify the requirements; no empirical method result exists in this dossier.

**Candidate control ladder, all PROPOSED_NOT_APPROVED:**

1. Frozen geometric Q transport / lifted coarse prediction, with support retained.
2. The same probabilities with one simple image-guided kernel or quadratic graph proposal; include image shuffle, constant image, false-edge and class-permutation controls. Pure interpolation does not invent named support absent in every source.
3. Soft aggregate observation fit plus the same single image relation, and a trust-region variant; use identical support/geometry. Include an exact-observation fit as a limit, not as the presumptive winner.
4. The same proposal/objective transferred into a conventional dense head, an unbounded D/U split, and the bounded current split, with matching pretrained initialization, data, schedule and capacity accounting. Compare fixed coarse paths versus trainable shared paths explicitly.
5. Only if authorized as a separate setting: re-evaluate a reviewed frozen backbone on native jittered views for feature reconstruction as in S4. Resizing cached Q is not this control. Feature gains still require a named semantic bridge. A per-image optimized upsampler at inference differs from fixed-feedforward single-cine inference and must be declared; no target-cohort fitting is implied.

**Layer/function implications.** The detail stem must receive image features whose within-cell variation correlates with a defensible signal. A zero final head can initially learn while blocking earlier detail-stem gradients; this expected two-stage gradient onset is not a bug. A shared decoder couples native and coarse behavior; a detached/frozen coarse path is the cleanest isolation control, not necessarily the best final model. `prepare_targets` must remain mass/support transport; any new observation objective belongs to a newly versioned policy. A native valid mask must participate in the mathematical operator, not merely decorate outputs. Logit bounds, class centering, observation representation, teacher resolution and dtype must be explicit configuration/evidence fields.

**Limitations/kill criteria.** Stop a claimed evidence mechanism if shuffled/constant images perform equivalently, if gradients arise only from padding/weight variation/interpolated targets, if a candidate cannot distinguish manufactured common-null alternatives, if small misregistration reverses it, or if apparent improvement comes only from copying Q more sharply. Passing these controls supports software/mechanism plausibility only. Without external task-valid evidence, do not claim better named cardiac anatomy, calibration, or generalization.

## Author clarification before cross-review — 2026-10-18 UTC

**R2-C2 probability-space capacity consequence (DERIVED_RESULT).** The per-class bound also gives a useful gauge-invariant necessary condition. For every pair of classes c,d and two pixels i,j in a cell, the actual bounded split satisfies

`|(ell_ic-ell_id) - (ell_jc-ell_jd)| < 4b`.

Proof: the coarse margin cancels between pixels; each per-class projected-detail difference equals the corresponding difference of pre-projection bounded values and has magnitude less than `2b`. The triangle inequality gives `4b`. Since `ell_ic-ell_id = log(p_ic/p_id)`, this is invariant to every pixelwise additive class gauge. It holds even if the coarse logits remain freely trainable. For binary class probabilities 0.99 and 0.01 in two pixels of the same cell, the required log-odds difference is `2 log(99) ≈ 9.19024`; the current `b = 1` branch cannot represent both probabilities. This does not preclude an argmax boundary at lower confidence. Thus the initial per-class residual criterion was intentionally not a complete probability characterization, but the architecture nevertheless has a concrete probability-space capacity limitation.

The strict tanh inequalities in C2 and this consequence are in real arithmetic for finite raw logits. Floating-point tanh can saturate to exactly ±1; use the closed `≤ 4b` bound plus arithmetic tolerance in numerical checks. The 9.19-versus-4 obstruction is unaffected.

**R2-C6 domain clarification.** The finite-logit lower sensitivity bound assumes a soft latent target with a positive segment probability floor; one-hot anatomical masks do not have finite exact softmax logits. Using that bound for hard masks requires a declared soft approximation and a separate margin/argmax argument. Neither a logit bound nor probability stability alone proves Dice improvement.
